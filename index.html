这是纯静态网页，所有数据只存在这台设备当前的浏览器里，不会上传到 GitHub 或任何服务器。 换手机、换浏览器或清理浏览器数据前，请先导出备份，到新环境再导入。

记录建议

幼宠建议每周固定同一天、同一台秤称一次，测量条件一致曲线才有可比性； 成年后改为每月一次即可。身长量鼻端到尾根，肩高量地面到肩胛骨最高点。
