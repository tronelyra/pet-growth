# 宠物成长记录

一个**单文件**的宠物生长记录网页，无需安装、无需账号、无需后端。用浏览器打开即可记录体重、身长、肩高、里程碑和成长照片，并自动绘制成长曲线。

线上地址：<https://tronelyra.github.io/pet-growth/>

本地使用：直接双击打开 `index.html`，或把文件放到任意静态服务器。

---

## 功能

| 模块 | 说明 |
|---|---|
| 宠物档案 | 名字、品种、性别、出生日期、头像；自动按生日计算实时年龄（X岁X月X天）与已陪伴天数 |
| 生长记录 | 按日期记录体重 / 身长 / 肩高 / 备注 / 当场照片，支持新增、编辑、删除 |
| 成长曲线 | Canvas 手绘折线图，可在体重、身长、肩高之间切换，悬浮或点按查看单点数值 |
| 里程碑 | 疫苗、驱虫、体检、绝育、换牙、第一次、新技能等事件，独立时间线展示 |
| 照片墙 | 自动汇集各次记录附带的照片，按日期排列，点击放大，直观对比成长变化 |
| 数据备份 | 一键导出 / 导入 JSON；照片在本地压缩后再存储，避免占满浏览器空间 |
| 示例数据 | 内置一套 6 个月幼犬生长示例，方便先看效果；可在「数据」页清空后从零开始 |

适配手机与桌面浏览器，移动端触控目标不小于 44px，曲线图支持点按取数。

## 数据存在哪里

**只存在你当前设备、当前浏览器的 `localStorage` 里。**

- 本仓库只有页面代码，**不包含任何宠物数据或照片**，GitHub 上看不到你的记录。
- 没有后端，不会上传、不会同步、不会统计。
- 换设备 / 换浏览器 / 清理浏览器数据前，请到「数据」页**导出 JSON 备份**，再到新环境导入。
- 建议把导出的 JSON 放到私有仓库或网盘长期存档。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，全部内联在 `index.html` 一个文件里。
- 不依赖任何 CDN、外部字体、外部图片或第三方库，断网也能正常使用。
- 图片经 `Canvas` 压缩为 JPEG（记录图最长边 900px，头像 420px）后以 data URL 存储。
- 曲线图为原生 `Canvas` 2D 绑定 `devicePixelRatio`，高清屏不发虚。

## 部署到 GitHub Pages

本页面已通过 `main` 分支根目录 + GitHub Pages 发布。若需自行部署：

1. 新建仓库，把 `index.html` 放在根目录。
2. `Settings → Pages → Build and deployment → Source` 选择 `Deploy from a branch`。
3. `Branch` 选 `main`、文件夹选 `/ (root)`，保存。
4. 约 1 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

免费版 GitHub Pages 仅支持公开仓库。由于数据全在浏览器本地，公开仓库不会暴露你的宠物信息；若希望只有自己能访问，可用私有仓库 + GitHub Pages Pro，或直接把 `index.html` 放在本机使用。

## 记录建议

- 幼宠每周固定同一天、同一台秤称一次，测量条件一致，曲线才有可比性；成年后改每月一次。
- 身长量鼻端到尾根，肩高量地面到肩胛骨最高点。
- 体重短期波动受进食、洗澡影响，看趋势不要盯单次数值。
